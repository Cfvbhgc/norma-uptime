> `norma-planner`, папка `deploy/uptime/`. Workflow здесь выключен, секреты удалены; репозиторий оставлен для истории.

Монитор доступности «НОРМА. Планер»: GitHub Actions раз в 10 минут запрашивает
`https://89-169-53-119.sslip.io/api/health`. Два падения подряд — сообщение в Telegram
(не чаще одного в час), после восстановления — одно сообщение «снова работает».

- Логика — `uptime/check.mjs`, расписание — `.github/workflows/uptime.yml`.
- Секреты репозитория: `TELEGRAM_BOT_TOKEN` (бот @publictam0_bot) и `ILYA_TG_ID` (кому писать).
- Состояние между запусками (сколько падений подряд, когда было извещение) — в кэше Actions.
- Тест: Actions → «Доступность» → Run workflow с другим адресом; у теста своё состояние, боевое не трогается.

Репозиторий публичный, чтобы минуты Actions не расходовались из лимита приватного `norma-planner`.
Если в репозитории 60 дней нет коммитов, GitHub отключает расписание — тогда включить его заново во вкладке Actions.
Проверить, что расписание работает: `gh run list --repo Cfvbhgc/norma-uptime --event schedule` — запуски должны идти
примерно раз в 10 минут (GitHub под нагрузкой может сдвигать их на несколько минут). Нет ни одного — выключить и
включить workflow (`gh workflow disable/enable uptime.yml`) или сделать коммит.
